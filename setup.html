Feedbackbot — agent setup

Nederlands

De 16 .md-bestanden bevatten de ongewijzigde instructies van de huidige pilotagents. De instellingen hieronder staan buiten de prompt.

  1. Open Microsoft 365 Copilot met je HU-account. Maak een nieuwe agent en kies Configure/Configureren.
  2. Kies het .md-bestand voor je cursus en taal. Plak de volledige inhoud in Instructions/Instructies. Upload het niet als kennisbron en laat de builder de tekst niet herschrijven.
  3. Geef de agent een naam, bijvoorbeeld ‘VHb Feedback NL pilot’. Kies Think deeper. Zet webzoekopdrachten en persoonlijke werkbronnen uit. Voeg geen kennisbronnen toe.
  4. Sla de agent op. Test met een fictief gesprek. Controleer de leeruitkomsten, de toeschrijving van docentfeedback en de lege beoordelingscellen. Sprekerslabels zijn niet vereist.
  5. Deel indien nodig de chat met HU-collega’s. De huidige pilotagents gebruiken HU-brede chattoegang, zonder catalogusindiening.

English

The 16 .md files contain the unchanged instructions of the current pilot agents. The settings below sit outside the prompt.

  1. Open Microsoft 365 Copilot with your HU account. Create a new agent and choose Configure.
  2. Choose the .md file for your course and language. Paste its full contents into Instructions. Do not upload it as a knowledge source or let the builder rewrite it.
  3. Name the agent, for example ‘MPb Feedback EN pilot’. Select Think deeper. Turn off web search and personal work sources. Add no knowledge sources.
  4. Save the agent. Test with a fictional conversation. Check the learning outcomes, attribution of teacher feedback and blank rating cells. Speaker labels are not required.
  5. If needed, share the chat with HU colleagues. The current pilot agents use HU-wide chat access without catalog submission.
